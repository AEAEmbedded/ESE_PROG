# Git workshops

Two hands-on Git workshops for Prog 5. Everything in Prog 5 and 6 is handed in through Git, so these come first.

| Workshop | When | Content | Document |
| --- | --- | --- | --- |
| 1. The basics | Friday 4 September 2026 | Setup, the four places, clone / add / commit / push, status and diff, `.gitignore`, handing in via your own repository | [`Workshop1_Basics.md`](Workshop1_Basics.md) |
| 2. Working together | later in period 1 | Branches and pull requests, collaborating and code review, merge conflicts, undo, `pull --rebase` | [`Workshop2_Collaboration.md`](Workshop2_Collaboration.md) |

Interactive version of both (progress, hints, self-checks, clickable model): [`index.html`](index.html) - open it in a browser.

Background material: the [HAN SE Git manual](../../Demos/Git%20manual%20SE%20HAN%20v1.1%20jakorten.pdf) and [`Prog5_Git.pdf`](../../Demos/Prog5_Git.pdf) in `Prog5/Demos/`.
